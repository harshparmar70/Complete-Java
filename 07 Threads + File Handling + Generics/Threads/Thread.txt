# 🔷 Threads in Java (Complete + Deep Understanding)

# 📌 Definition

A **Thread** is the smallest unit of execution inside a process.

👉 OR

```text id="x7m2qp"
A thread is a lightweight subprocess.
```

---

# 🧠 Simple Meaning

A thread allows:

```text id="u4q8wr"
Multiple tasks to run simultaneously
```

inside one program.

---

# 🔥 Real-Life Example

In mobile phone:

* Music playing 🎵
* Download running ⬇
* WhatsApp notifications 📩

at same time.

👉 Achieved using:

```text id="m9k1vn"
Threads
```

# 🔷 Thread Lifecycle (VERY IMPORTANT)

```text id="p3m7zy"
New
 ↓
Runnable
 ↓
Running
 ↓
Blocked/Waiting
 ↓
Terminated
```

---

# 🔷 1️⃣ New State

Thread object created.

```java id="r6q2wp"
Thread t = new Thread();
```

---

# 🔷 2️⃣ Runnable State

After:

```java id="v1m8qx"
t.start();
```

Thread ready to run.

---

# 🔷 3️⃣ Running State

CPU executes:

```java id="f4q9wr"
run()
```

method.

---

# 🔷 4️⃣ Blocked/Waiting State

Thread waiting because of:

* sleep()
* waiting
* resource lock

---

# 🔷 5️⃣ Terminated State

Thread execution finished.

---

# 🔷 Ways to Create Thread

Java provides:

1. Extending Thread class
2. Implementing Runnable interface

---

# 🔷 Method 1 → Extending Thread Class

---

# 💻 Example

```java id="x8m2vn"
class MyThread extends Thread {

    public void run() {

        System.out.println("Thread is running");
    }
}

public class Demo {

    public static void main(String[] args) {

        MyThread t = new MyThread();

        t.start();
    }
}
```

---

# 👉 Output

```text id="w5q7zy"
Thread is running
```

---

# 🧠 Important

```java id="t2m6wr"
start()
```

creates new thread internally.

Then JVM calls:

```java id="k4m8zy"
run()
```

---

# ⚠️ Difference Between start() and run()

| start()            | run()              |
| ------------------ | ------------------ |
| Creates new thread | Normal method call |
| Multithreading     | No multithreading  |

---

# 🔷 Method 2 → Runnable Interface (BEST PRACTICE)

---

# 💻 Example

```java id="r9q3wp"
class MyThread implements Runnable {

    public void run() {

        System.out.println("Thread running");
    }
}

public class Demo {

    public static void main(String[] args) {

        MyThread obj = new MyThread();

        Thread t = new Thread(obj);

        t.start();
    }
}
```

---

# 🔥 Why Runnable Better?

Because Java supports:

```text id="m1v7qx"
Single inheritance
```

If class already extends another class:

* Cannot extend Thread again

Runnable solves this.

---

# 🔷 Multiple Threads Example

---

# 💻 Example

```java id="y6m2wr"
class A extends Thread {

    public void run() {

        for(int i=1; i<=5; i++) {

            System.out.println("A: " + i);
        }
    }
}

class B extends Thread {

    public void run() {

        for(int i=1; i<=5; i++) {

            System.out.println("B: " + i);
        }
    }
}

public class Demo {

    public static void main(String[] args) {

        A t1 = new A();
        B t2 = new B();

        t1.start();
        t2.start();
    }
}
```

# 🔷 Synchronization (VERY IMPORTANT)

---

# 📌 Problem

Multiple threads accessing same resource can create:

```text id="g1m8zy"
Race condition
```

---

# 💻 Example

Suppose:

* Two threads updating bank balance

Wrong results possible.

---

# 🔷 Solution → synchronized

---

# 💻 Example

```java id="r8q2vp"
synchronized void display() {

}
```

Only one thread allowed at a time.
