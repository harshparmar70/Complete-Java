# 🔷 Interface in Java (Complete + Exam-Ready)

# 📌 Definition

An **Interface** in Java is a blueprint of a class that contains:

* abstract methods
* constants

👉 It is used to achieve:

```text id="u7k3wp"
Abstraction + Multiple Inheritance
```

---

# 🧠 Simple Meaning

Interface tells:

```text id="x2m8vq"
WHAT to do
```

Class tells:

```text id="r5q1wr"
HOW to do
```

---

# 🔷 Why Interface Needed?

Used for:

* 100% abstraction
* Multiple inheritance
* Standard design

---

# 🔷 Important Points

## ✔ Interface methods are:

```text id="m9k4zy"
public abstract
```

by default

---

## ✔ Interface variables are:

```text id="p3m7qn"
public static final
```

by default

---

# 🔷 Syntax

```java id="v6q2wp"
interface InterfaceName {

    void show();
}
```

---

# 🔷 Implementing Interface

Use keyword:

```java id="n1m8vx"
implements
```

---

# 💻 Basic Example

```java id="f4q7wr"
interface Animal {

    void sound();
}

class Dog implements Animal {

    public void sound() {

        System.out.println("Dog barks");
    }
}

public class Demo {

    public static void main(String[] args) {

        Dog d = new Dog();

        d.sound();
    }
}
```

---

# 👉 Output

```text id="x8m2qy"
Dog barks
```

---

# 🧠 Important Rule

When implementing interface methods:

```text id="w5q9vn"
Method must be public
```

Because interface methods are public by default.

# 🔷 Multiple Inheritance Using Interface

Java does NOT support:

```text id="k4m8zy"
Multiple inheritance with classes
```

BUT supports:

```text id="r9q3wp"
Multiple inheritance with interfaces
```

---

# 💻 Example

```java id="m1v7qx"
interface A {

    void show();
}

interface B {

    void display();
}

class Test implements A, B {

    public void show() {
        System.out.println("Show");
    }

    public void display() {
        System.out.println("Display");
    }
}

public class Demo {

    public static void main(String[] args) {

        Test t = new Test();

        t.show();
        t.display();
    }
}
```

---

# 👉 Output

```text id="y6m2wr"
Show
Display
```

---

# 🔷 Interface vs Class

| Feature              | Interface | Class           |
| -------------------- | --------- | --------------- |
| Object Creation      | ❌ No      | ✔ Yes           |
| Constructors         | ❌ No      | ✔ Yes           |
| Methods              | Abstract  | Normal/Abstract |
| Multiple Inheritance | ✔ Yes     | ❌ No            |

---

# 🔷 Interface vs Abstract Class

| Feature     | Interface                      | Abstract Class    |
| ----------- | ------------------------------ | ----------------- |
| Methods     | Fully abstract (traditionally) | Abstract + normal |
| Variables   | final/static                   | Any type          |
| Inheritance | Multiple                       | Single            |

---

