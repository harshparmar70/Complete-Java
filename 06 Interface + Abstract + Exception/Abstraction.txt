# 🔷 Abstraction in Java (Complete + Exam-Ready)

# 📌 Definition

**Abstraction** means:

```text id="u8m3qp"
Hiding implementation details and showing only essential features
```

---

# 🧠 Simple Meaning

```text id="x2q7wr"
WHAT to do  
not HOW to do
```

---

# 🔥 Real-Life Example

## 🚗 Car

You use:

* Steering
* Brake
* Accelerator

BUT you don’t know:

* Engine internals
* Gear mechanism

👉 This is:

```text id="m5k1vn"
Abstraction
```

---

# 🔷 Why Abstraction Needed?

✔ Reduce complexity
✔ Improve security
✔ Hide unnecessary details
✔ Focus on important features

---

# 🔷 Ways to Achieve Abstraction

Java provides:

1. Abstract Class
2. Interface

---

# 🔷 Abstract Class

---

# 📌 Definition

A class declared using:

```java id="p9m4zy"
abstract
```

keyword is called abstract class.

---

# 🔷 Important Rules

✔ Can contain:

* Abstract methods
* Normal methods

✔ Cannot create object directly

---

# 🔷 Abstract Method

Method without body

---

# 💻 Syntax

```java id="r3q8wp"
abstract void show();
```

---

# 💻 Example

```java id="t6m2qx"
abstract class Animal {

    abstract void sound();
}

class Dog extends Animal {

    void sound() {

        System.out.println("Dog barks");
    }
}

public class Demo {

    public static void main(String[] args) {

        Dog d = new Dog();

        d.sound();
    }
}
```

---

# 👉 Output

```text id="w1q7vn"
Dog barks
```

---

# 🧠 Understanding

---

## 🔹 Parent class

```java id="k4m9wr"
abstract class Animal
```

Cannot define exact sound.

---

## 🔹 Child class

```java id="n8q2vp"
class Dog extends Animal
```

Provides implementation.

---

# 🔷 Can Abstract Class Have Normal Methods?

✔ YES

---

# 💻 Example

```java id="u5m1zy"
abstract class Animal {

    void eat() {

        System.out.println("Animal eats");
    }

    abstract void sound();
}
```

---

# 🔷 Can We Create Object of Abstract Class?

❌ NO

---

# 💻 Invalid Example

```java id="x7q4wr"
Animal a = new Animal(); // ❌ Error
```

---

# 🔷 Reference Allowed

✔ YES

```java id="m2k8vn"
Animal a = new Dog();
```

---

# 🔷 Important Characteristics

| Feature          | Abstract Class |
| ---------------- | -------------- |
| Object Creation  | ❌ No           |
| Constructors     | ✔ Yes          |
| Abstract Methods | ✔ Yes          |
| Normal Methods   | ✔ Yes          |

---

# 🔷 Abstraction Using Interface

Interface gives:

```text id="p6m3qx"
100% abstraction
```

(traditionally)

---

# 💻 Example

```java id="v9q1wp"
interface Shape {

    void draw();
}

class Circle implements Shape {

    public void draw() {

        System.out.println("Drawing Circle");
    }
}
```

---

# 🔷 Abstract Class vs Interface

| Feature              | Abstract Class    | Interface           |
| -------------------- | ----------------- | ------------------- |
| Methods              | Abstract + Normal | Abstract (mainly)   |
| Variables            | Any type          | public static final |
| Multiple Inheritance | ❌                 | ✔                   |
| Constructor          | ✔                 | ❌                   |

---

# 🔷 Important Point

Abstraction focuses on:

```text id="y4m7wr"
Hiding implementation
```

while Encapsulation focuses on:

```text id="f1q9vn"
Data hiding
```

---

# 🔷 Abstraction Process

```text id="t8m2zy"
Abstract class/interface
        ↓
Child class implements methods
        ↓
User uses final functionality
```

---

## Payment System

Interface:

```java id="r5m1qp"
pay()
```

Classes:

User only knows:


👉 Abstraction in Java is the process of hiding implementation details and showing only essential functionality. It is achieved using abstract classes and interfaces.
