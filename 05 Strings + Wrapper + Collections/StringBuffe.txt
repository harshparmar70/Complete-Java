# 🔷 StringBuffer in Java (Complete + Exam-Ready)

## 📌 Definition

`StringBuffer` is a class in Java used to create **mutable strings**.

👉 Mutable means:

```text id="x8p2vn"
String content can be changed
```

---

# 🧠 Why StringBuffer Needed?

Normal `String` objects are:

```text id="u5m1zk"
Immutable
```

Every modification creates a new object.

👉 This wastes:

* Memory
* Time

So Java introduced:

```text id="n7q4yb"
StringBuffer
```

---

# 🔷 String vs StringBuffer

| Feature          | String | StringBuffer |
| ---------------- | ------ | ------------ |
| Mutable          | ❌ No   | ✔ Yes        |
| Memory Efficient | ❌ Less | ✔ More       |
| Thread Safe      | ✔ Yes  | ✔ Yes        |
| Performance      | Slow   | Faster       |

---

# 💻 StringBuffer Example

## 👉 Output

👉 Original object modified

# 🔷 How StringBuffer Works

```java id="f1r8wy"
StringBuffer sb = new StringBuffer("Java");
```

👉 Creates mutable character sequence


## 🔹 insert()


# 💻 Complete Example

```java id="z4k7pm"
public class Demo {

    public static void main(String[] args) {

        StringBuffer sb = new StringBuffer("Java");

        sb.append(" Programming");

        sb.insert(4, " Language");

        System.out.println(sb);

        sb.reverse();

        System.out.println(sb);
    }
}
```


* Safe for multithreading
* Slightly slower

# 🔁 String vs StringBuffer vs StringBuilder

| Feature     | String | StringBuffer | StringBuilder |
| ----------- | ------ | ------------ | ------------- |
| Mutable     | ❌      | ✔            | ✔             |
| Thread Safe | ✔      | ✔            | ❌             |
| Speed       | Slow   | Medium       | Fast          |

# 🎯 Exam Answer (Perfect)

👉 StringBuffer is a mutable class in Java used to modify strings without creating new objects. It is thread-safe and provides methods like append(), insert(), delete(), and reverse().
