# 🔷 ArrayList in Java (Complete + Exam-Ready)

# 📌 Definition

`ArrayList` is a class in Java that provides a **dynamic array**.

👉 Dynamic means:

```text id="x1m7qp"
Size can grow or shrink automatically
```

---

# 🧠 Why ArrayList?

Normal arrays:

* Fixed size

ArrayList:

* Flexible size
* Easy insertion/deletion

---

# 🔷 Package

```java id="v4q8wr"

```

---

# 🔷 Syntax

```java id="m9k2vn"

```

---

# 💻 Example


# 🔷 Full Example

```java id="k4q8vn"
import java.util.ArrayList;

public class Demo {

    public static void main(String[] args) {

        ArrayList<String> list = new ArrayList<>();

        list.add("Java");
        list.add("Python");
        list.add("C");

        System.out.println(list);

        list.remove(1);

        System.out.println(list);

        System.out.println(list.get(0));

        System.out.println(list.size());
    }
}
```

# 🔷 ArrayList Internal Working

👉 Internally uses:

```text id="t6m4qp"
Resizable array
```

When capacity full:

* New larger array created
* Old data copied

---

# 🔷 Advantages

✔ Dynamic size
✔ Fast retrieval
✔ Easy to use

---

# ⚠️ Disadvantages

❌ Slow insertion/deletion in middle

---

# 🔷 Array vs ArrayList

| Feature    | Array              | ArrayList    |
| ---------- | ------------------ | ------------ |
| Size       | Fixed              | Dynamic      |
| Data Types | Primitive + Object | Objects only |
| Methods    | ❌                  | ✔            |

# 🔷 HashMap in Java (VERY IMPORTANT 🔥)

# 📌 Definition

`HashMap` stores data in:

```text id="c8q1vn"
Key → Value pair
```

---

# 🧠 Example

```text id="m5k7wr"
101 → Harsh
102 → Raj
```

---

# 🔷 Package

```java id="u3m9qx"
import java.util.HashMap;
```

---

# 🔷 Syntax

```java id="n7q2zy"

```

---

# 💻 Example

```java id="f4m8wp"
import java.util.HashMap;

public class Demo {

    public static void main(String[] args) {

        HashMap<Integer, String> map = new HashMap<>();

        map.put(101, "Harsh");
        map.put(102, "Raj");

        System.out.println(map);
    }
}
```

---

# 👉 Output


# 2️⃣ get()


# 🔷 Full Example

```java id="m2k8vn"
import java.util.HashMap;

public class Demo {

    public static void main(String[] args) {

        HashMap<Integer, String> map = new HashMap<>();

        map.put(101, "Harsh");
        map.put(102, "Raj");
        map.put(103, "Amit");

        System.out.println(map);

        System.out.println(map.get(101));

        map.remove(102);

        System.out.println(map);

        System.out.println(map.containsKey(103));
    }
}
```

---


# 🔷 Important Characteristics of HashMap

| Feature          | HashMap    |
| ---------------- | ---------- |
| Order Maintained | ❌ No       |
| Duplicate Keys   | ❌ No       |
| Duplicate Values | ✔ Yes      |
| Null Key         | ✔ One      |
| Null Values      | ✔ Multiple |

---

# 🔷 Internal Working

HashMap uses:

```text id="y7q4vn"
Hashing
```

to store and retrieve data quickly.

---

# 🔷 ArrayList vs HashMap

| Feature | ArrayList     | HashMap         |
| ------- | ------------- | --------------- |
| Stores  | Single values | Key-value pairs |
| Access  | Index         | Key             |
| Order   | Maintained    | Not guaranteed  |

---

# 🎯 Exam Answer (Perfect)

👉 ArrayList is a dynamic array implementation in Java used to store ordered collections of objects. HashMap is a collection class used to store data in key-value pairs using hashing.
