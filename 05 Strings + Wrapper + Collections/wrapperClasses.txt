# 🔷 Wrapper Classes in Java (Complete + Exam-Ready)

## 📌 Definition

Wrapper classes are classes that convert **primitive data types into objects**.

👉 In simple words:

```text id="y7m3qp"
Primitive → Object
```

---

# 🧠 Why Wrapper Classes Needed?

Java Collections work only with:

```text id="v2k8wn"
Objects
```

NOT primitive types.

Example:

```java id="f6q1zr"
ArrayList<int> ❌
ArrayList<Integer> ✔
```

So Java provides wrapper classes.

---

# 🔷 Primitive Types and Wrapper Classes

| Primitive Type | Wrapper Class |
| -------------- | ------------- |
| byte           | Byte          |
| short          | Short         |
| int            | Integer       |
| long           | Long          |
| float          | Float         |
| double         | Double        |
| char           | Character     |
| boolean        | Boolean       |

---

# 🔥 Example

```java id="x4m9vq"
int a = 10;

Integer obj = Integer.valueOf(a);

System.out.println(obj);
```

---

# 👉 Output

```text id="n8p2wy"
10
```

---

# 🔥 Autoboxing (VERY IMPORTANT)

## 📌 Definition

Automatic conversion:

```text id="z9k4wm"
primitive → wrapper object
```

Done automatically by compiler.

---

# 💻 Example

```java id="r2m8qx"
int a = 10;

Integer obj = a;
```

👉 Compiler internally converts:

```java id="t6p1vn"
Integer.valueOf(a)
```

---

# 🔥 Auto-Unboxing

## 📌 Definition

Automatic conversion:

```text id="f3q7wr"
wrapper object → primitive
```

---

# 💻 Example

```java id="k8m2zy"
Integer obj = 20;

int a = obj;
```

👉 Compiler internally converts:

```java id="p4v9qx"
obj.intValue()
```

---

# 🔷 Full Example

```java id="w1m6pk"
public class Demo {

    public static void main(String[] args) {

        // Autoboxing
        int a = 10;

        Integer obj = a;

        // Auto-unboxing
        int b = obj;

        System.out.println(a);
        System.out.println(obj);
        System.out.println(b);
    }
}
```

---

# 👉 Output

```text id="x7q3wn"
10
10
10
```

# 📌 What is Autoboxing?

## Definition

**Autoboxing** is the automatic conversion of:

```text id="v8k2wp"
Primitive type → Wrapper object
```

done automatically by Java compiler.

---

# 🧠 Example

```java id="m3q7vn"
int a = 10;

Integer obj = a;
```

👉 Compiler automatically converts:

```java id="p6m1qx"
Integer obj = Integer.valueOf(a);
```

This process is called:

```text id="t4k9wr"
Autoboxing
```

---

# 🔷 Why Needed?

Collections store:

```text id="x2m8zy"
Objects only
```

NOT primitive types.

Example:

```java id="r5q1wp"
ArrayList<Integer> list = new ArrayList<>();
```

---

# 💻 Full Example of Autoboxing

```java id="n7m3vq"
public class Demo {

    public static void main(String[] args) {

        int a = 100;

        Integer obj = a;

        System.out.println(a);
        System.out.println(obj);
    }
}
```

---

# 👉 Output

```text id="u1k6wr"
100
100
```

---

# 🔷 What is Unboxing?

## Definition

**Unboxing** is the automatic conversion of:

```text id="f9m2qx"
Wrapper object → Primitive type
```

---

# 🧠 Example

```java id="w4q8vn"
Integer obj = 50;

int a = obj;
```

👉 Compiler automatically converts:

```java id="k7m1zy"
int a = obj.intValue();
```

This process is called:

```text id="p3q6wr"
Unboxing
```

---

# 💻 Full Example of Unboxing

```java id="x5m9vq"
public class Demo {

    public static void main(String[] args) {

        Integer obj = 200;

        int a = obj;

        System.out.println(obj);
        System.out.println(a);
    }
}
```

---

# 👉 Output

```text id="c8k2wp"
200
200
```
