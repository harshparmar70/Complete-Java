## 🔷 `break` Statement in Java

### 📌 Definition

`break` is used to **immediately terminate a loop or switch-case** and move control **outside** of it.

---

# 🧩 Syntax

```java
break;
```

---

# 🔁 1️⃣ `break` in Loops

👉 Stops the loop as soon as condition is met

### 💻 Example:

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }
    System.out.println(i);
}
```

👉 Output:

```
1 2 3 4
```

👉 Loop stops when `i = 5`

---

# 🔁 2️⃣ `break` in `switch`

👉 Prevents **fall-through**

```java
int day = 2;

switch(day) {
    case 1:
        System.out.println("Mon");
        break;
    case 2:
        System.out.println("Tue");
        break;
    default:
        System.out.println("Invalid");
}
```

👉 Output:

```
Tue
```

---

# 🔥 Without `break` (Fall-through)

```java
int day = 2;

switch(day) {
    case 1:
        System.out.println("Mon");
    case 2:
        System.out.println("Tue");
    case 3:
        System.out.println("Wed");
}
```

👉 Output:

```
Tue
Wed
```

---

# 🧠 Labeled `break` (Advanced 🔥)

👉 Used to break **outer loop**

```java
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) {
            break outer;
        }
        System.out.println(i + " " + j);
    }
}
```

👉 Breaks both loops at once

---

# ⚠️ Important Points

* ✔ Works with loops and switch
* ✔ Immediately exits the block
* ❌ Cannot be used outside loop/switch

---

# 🔁 `break` vs `continue`

| Feature | break      | continue            |
| ------- | ---------- | ------------------- |
| Action  | Stops loop | Skips iteration     |
| Flow    | Exit loop  | Continue next cycle |

---

# 🎯 Exam Answer (Short)

👉 The `break` statement is used to terminate a loop or switch-case immediately and transfer control to the next statement after it.

---

# ❓ Viva Questions

👉 **1. What does break do?**
Stops execution

👉 **2. Where can we use break?**
Loops and switch

👉 **3. What is labeled break?**
Breaks outer loop

## 🔷 `continue` Statement in Java

### 📌 Definition

`continue` is used to **skip the current iteration** of a loop and move to the **next iteration**.

👉 Unlike `break`, it **does NOT stop the loop**, it just skips one cycle.

---

# 🧩 Syntax

```java id="f1d3xk"
continue;
```

---

# 🔁 How It Works

* When `continue` is executed:

  * Remaining code in that iteration is skipped
  * Loop jumps to next iteration

---

# 💻 Example (for loop)

```java id="qbh2wh"
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}
```

👉 Output:

```id="ljd8z6"
1 2 4 5
```

👉 `3` is skipped

---

# 💻 Example (while loop)

```java id="2qrs2c"
int i = 1;

while (i <= 5) {
    i++;
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}
```

👉 Skips printing `3`

---

# 🔥 Important Difference

| Feature         | break                 | continue            |
| --------------- | --------------------- | ------------------- |
| Effect          | Stops loop completely | Skips one iteration |
| Loop continues? | ❌ No                  | ✔ Yes               |

---

# 🧠 Labeled `continue` (Advanced 🔥)

👉 Skips to next iteration of **outer loop**

```java id="v9gk2u"
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            continue outer;
        }
        System.out.println(i + " " + j);
    }
}
```

---

# ⚠️ Important Points

* ✔ Used only in loops
* ✔ Skips current iteration
* ❌ Cannot be used outside loops

---

# 🎯 Exam Answer (Short)

👉 The `continue` statement skips the current iteration of a loop and continues with the next iteration.

---

# ❓ Viva Questions

👉 **1. Does continue stop the loop?**
❌ No

👉 **2. Where is continue used?**
✔ Inside loops

👉 **3. Difference between break and continue?**

* break → exit loop
* continue → skip iteration

---

# 💡 Pro Tip

👉 Use `continue` when:

* You want to **ignore specific values**
* Example:

  * Skip negative numbers
  * Skip even numbers

## 🔷 Labelled Loops in Java

### 📌 Definition

A **labelled loop** is a loop with a **name (label)** that allows you to control **outer loops** using `break` or `continue`.

👉 Useful when you have **nested loops**

---

# 🧩 Syntax

```java id="76uepr"
labelName:
for (...) {
    for (...) {
        break labelName;     // or continue labelName;
    }
}
```

---

# 🔁 1️⃣ Label with `break`

👉 Used to **exit outer loop directly**

### 💻 Example:

```java id="ixx6wg"
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) {
            break outer;
        }
        System.out.println(i + " " + j);
    }
}
```

### 👉 Output:

```id="xtvwxz"
1 1
1 2
1 3
2 1
```

👉 Loop stops completely at `(2,2)`

---

# 🔁 2️⃣ Label with `continue`

👉 Used to **skip to next iteration of outer loop**

### 💻 Example:

```java id="lca6qv"
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            continue outer;
        }
        System.out.println(i + " " + j);
    }
}
```

### 👉 Output:

```id="kn0o9g"
1 1
2 1
3 1
```

👉 Skips rest of inner loop when `j == 2`

---

# 🧠 Why Use Labelled Loops?

Without labels:

* `break` → exits only **inner loop**

With labels:

* `break label` → exits **outer loop**
* `continue label` → jumps to next iteration of outer loop

---

# ⚠️ Important Points

* ✔ Label must be placed **before loop**
* ✔ Can be used with `for`, `while`, `do-while`
* ❌ Overuse makes code hard to read

---

# 🔁 Normal vs Labelled

| Feature  | Normal Loop     | Labelled Loop       |
| -------- | --------------- | ------------------- |
| break    | Inner loop only | Outer loop possible |
| continue | Inner loop      | Outer loop possible |

---

# 🎯 Exam Answer (Short)

👉 A labelled loop is a loop with a label that allows control of outer loops using `break` and `continue` statements.

---
