## 🔷 Control Statements: `if`, `if-else`, `else-if` (Java)

These are used for **decision making**—your program chooses what to do based on conditions.

---

# 1️⃣ `if` Statement

### 📌 Use:

Execute block **only if condition is true**

### 💻 Syntax:

```java
if (condition) {
    // code executes if true
}
```

### ✅ Example:

```java
int age = 18;

if (age >= 18) {
    System.out.println("Eligible to vote");
}
```

---

# 2️⃣ `if-else` Statement

### 📌 Use:

Choose between **two options**

### 💻 Syntax:

```java
if (condition) {
    // true block
} else {
    // false block
}
```

### ✅ Example:

```java
int num = 5;

if (num % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}
```

---

# 3️⃣ `else-if` Ladder

### 📌 Use:

Check **multiple conditions**

### 💻 Syntax:

```java
if (condition1) {
    // block 1
} else if (condition2) {
    // block 2
} else if (condition3) {
    // block 3
} else {
    // default block
}
```

---

### ✅ Example (Grading System):

```java
int marks = 75;

if (marks >= 90) {
    System.out.println("Grade A");
} else if (marks >= 75) {
    System.out.println("Grade B");
} else if (marks >= 50) {
    System.out.println("Grade C");
} else {
    System.out.println("Fail");
}
```

---

# 🧠 How It Works

* Conditions are checked **top to bottom**
* First **true condition executes**
* Remaining conditions are skipped

---

# ⚠️ Important Rules

* Condition must return **boolean (true/false)**
* Use `{}` for multiple statements
* Avoid confusing `=` with `==`

---

# 🔥 Nested `if` (Extra)

```java
int age = 20;
boolean hasLicense = true;

if (age >= 18) {
    if (hasLicense) {
        System.out.println("Can drive");
    }
}
```

---

# 🔁 Quick Comparison

| Type      | Use                 |
| --------- | ------------------- |
| `if`      | Single condition    |
| `if-else` | Two choices         |
| `else-if` | Multiple conditions |

---

# 🎯 Exam Answer (Short)

👉 `if`, `if-else`, and `else-if` are decision-making statements used to execute code based on conditions. `if` checks one condition, `if-else` provides two options, and `else-if` handles multiple conditions.

## 🔷 `switch-case` in Java (Clear + Exam-Ready)



switch-case
### 📌 Definition

`switch-case` is a **selection statement** used to choose one block of code from multiple options.

👉 Best when you have **fixed choices** (menu, operations, grades, etc.)

---

# 🧩 Syntax

```java
switch (expression) {
    case value1:
        // code
        break;

    case value2:
        // code
        break;

    ...

    default:
        // runs if no case matches
}
```

---

# 🧠 How It Works

* `expression` is evaluated once
* Compared with each `case`
* Matching case executes
* `break` stops further execution

# ⚠️ Important Points

### ✔ `break` is important

Without it → fall-through happens

---

## 🔥 Fall-Through Example

```java
int day = 2;

switch(day) {
    case 1:
        System.out.println("Mon");
    case 2:
        System.out.println("Tue");
    case 3:
        System.out.println("Wed");
}
```

👉 Output:

```text
Tue
Wed
```

👉 Because no `break`

❌ Not allowed: `float`, `double`, `boolean`

---

# 🆕 Modern Switch (Java 14+)

```java
int day = 2;

switch(day) {
    case 1 -> System.out.println("Mon");
    case 2 -> System.out.println("Tue");
    default -> System.out.println("Invalid");
}
```

👉 Cleaner and no need for `break`

---

# 🔁 if-else vs switch

| Feature     | if-else              | switch       |
| ----------- | -------------------- | ------------ |
| Condition   | Complex              | Fixed values |
| Readability | Medium               | High         |
| Performance | Slower (many checks) | Faster       |

---

# 🎯 Exam Answer (Short)

👉 `switch-case` is a control statement used to select one of many blocks based on the value of an expression. It improves readability when dealing with multiple fixed conditions.

---
